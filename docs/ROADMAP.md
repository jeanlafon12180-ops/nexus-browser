# NEXUS BROWSER — Roadmap

All milestones are planned; a milestone is complete only after its acceptance criteria are tested.

## 0.1.0-alpha — Foundation
- [x] Create the GitHub repository.
- [x] Document the Firefox-based technical direction.
- [x] Define initial privacy principles.
- [ ] Select and pin the Mozilla source baseline.
- [ ] Prepare a reproducible local build environment.
- [ ] Produce the first unmodified Firefox-based test build.

## 0.2.0-alpha — NEXUS browser shell
- [ ] Apply NEXUS branding.
- [ ] Establish default theme and start page.
- [ ] Verify tabs, navigation and address bar.
- [ ] Create Windows development build.

## 0.3.0-alpha — Everyday browsing
- [ ] Configure bookmarks and history.
- [ ] Validate downloads.
- [ ] Configure private browsing entry points.
- [ ] Test profile isolation and permissions.

## 0.4.0-alpha — Privacy
- [ ] Review Enhanced Tracking Protection defaults.
- [ ] Add clear privacy settings.
- [ ] Document telemetry behavior.
- [ ] Run security and regression checks.

## 0.5.0-alpha — NEXUS IA
- [ ] Design an opt-in assistant integration.
- [ ] Document data flows and retention.
- [ ] Keep AI requests disabled until the user enables them.

## 1.0.0 — Stable release
- [ ] Windows release build and installer.
- [ ] macOS release build and package.
- [ ] Linux packages and installation instructions.
- [ ] Update and rollback process.
- [ ] Publish licenses, privacy policy and release notes.

## Status vocabulary

- **Planned:** not started.
- **In progress:** actively being implemented.
- **Complete:** implemented and verified.
